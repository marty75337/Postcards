Using your Collection Register

Start: your Céline card is included as the first record. Tap any field to edit it, or Add item to create a record.

Images: add JPEG, PNG, WebP or PDF files. Label each front, reverse, unfolded sheet or detail. Photos can be enlarged. PDFs open in your browser’s PDF viewer.

Save: changes are stored in this browser using IndexedDB. Wait for “Saved on this device”. Private browsing, clearing website data or changing the website address can remove or separate these records.

Back up: Export backup includes every record and its images/PDFs. Choose a meaningful filename and save the JSON file in Files or iCloud Drive. Import backup on another device to transfer the collection. Import adds records and replaces matching record IDs after confirmation.

Privacy: the app does not send your added records to a server. The supplied Céline example is part of the app files; it will be visible to visitors if you publish those files on a public website. A private code repository alone does not protect a published website.

Scan processing: New uploads generate JPGs automatically. Originals are retained. Image cards have Rotate left and Rotate right buttons; each click turns the image 90 degrees and saves it. Use Process existing uploads on the Images tab for earlier attachments. When paper edges are uncertain, the full scan is retained. Export a backup before updating the app.

Research: initial readings are provisional. Record sources and unresolved questions; this version does not automatically transcribe or research items.

Printing: Print record prints the current item’s text and image attachments. Original PDFs can be downloaded separately. Use A4 in your print dialogue.
